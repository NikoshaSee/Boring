# ExcuseFlow: Система учета нарушений с банком отмазок

## Описание проекта
Информационная система для фиксации нарушений дисциплины и ведения банка отмазок. 
Система позволяет создавать нарушения, привязывать к ним отмазки (от душных до сверхкреативных), оценивать их рейтингом и формировать отчеты.

## Стек технологий
- **Язык:** Python 3.13
- **Фреймворк:** FastAPI (REST API)
- **База данных:** SQLite (SQLAlchemy ORM)
- **Аутентификация:** JWT (JSON Web Tokens), OAuth2
- **Тестирование:** Pytest
- **Документация:** Swagger UI (встроенная в FastAPI)

## Архитектура и модули
1. **AuthModule:** Регистрация, вход, роли (admin, inspector, violator).
2. **ViolationModule:** CRUD нарушений, смена статусов (фиксация, рассмотрение, закрытие).
3. **ExcuseModule:** Банк отмазок с категориями (dumb, medium, creative, super_creative), рейтинг.
4. **ReportModule:** Формирование топа отмазок.

## Установка и запуск
1. Установить зависимости:
   `pip install -r requirements.txt`
2. Заполнить базу тестовыми данными (отмазками):
   `python seed.py`
3. Запустить сервер:
   `uvicorn main:app --reload`

## Документация API
После запуска сервера документация доступна по адресу: `http://127.0.0.1:8000/docs`
